Ouvre cette page sur les deux appareils. Associe-les, puis envoie tes fichiers directement entre les navigateurs.

Commence par créer une connexion sur un seul appareil.

1. Associer les appareils

Sur le premier appareil
Crée une invitation, copie le code et transmets-le à ton autre appareil par un moyen privé.

Sur le deuxième appareil
Colle l’invitation reçue ci-dessous et génère une réponse. Renvoie cette réponse au premier appareil.

Sur le premier appareil, colle ensuite la réponse et clique aussi sur « Utiliser le code reçu ».

2. Envoyer des fichiers

Le destinataire devra accepter chaque fichier. Garde les deux pages ouvertes et les écrans éveillés.

En attente de connexion.

Réception

Aucun fichier en attente.

GitHub Pages héberge l’interface, pas tes fichiers. Le service STUN de Google aide à trouver une connexion directe. Certains réseaux nécessitent un relais TURN, absent de cette version : essaie le même Wi-Fi si la connexion échoue. Aucun débit maximal garanti. Sans enregistrement direct sur disque, réception limitée à 256 Mio par fichier pour limiter l’usage mémoire. Pas de reprise après interruption.
